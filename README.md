## 🎯 Overview
`starey-omni-lead-enricher` is an enterprise-grade data extraction and lead prospecting framework. It scrapes target company metrics, validates corporate emails, and calculates real-time intent scores using JSON schema validation.

## ✨ Key Features
- **Multi-Source Scraping:** Aggregates business data from public directories and web endpoints.
- **Automated Schema Validation:** Ensures strict data integrity using standardized JSON schemas.
- **Intent Scoring Engine:** Ranks prospects based on company size, engagement, and tech stack match.

## 🛠️ Stack & Architecture
- **Core Engine:** Python, REST APIs, Webhook Handlers
- **Data Schema:** Strict JSON Schema Validation
- **Agency Security:** Rate-limited requests & secure proxy rotation
